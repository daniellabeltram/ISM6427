# Weather

A simple glassmorphic weather app powered by the free [Open-Meteo API](https://open-meteo.com/) (no API key needed). Defaults to Boca Raton, FL, and lets you search any city.

## Run locally
Open `index.html` in a browser.

## Deploy to Netlify
Drag this folder into Netlify, or connect the repo with no build command and `.` as the publish directory.
