# Shelf

A simple, elegant book app showing the top 5 trending books, the top 3 genres, and the top 10 US authors. Book covers, author photos and genre picks come live from the free [Open Library](https://openlibrary.org/developers/api) API (no key needed).

The earlier weather app lives in `weather/`.

Plain HTML/CSS/JS — no build step. To deploy on Netlify, drag this folder in (or connect the repo) with no build command and publish directory `.`.
