# ISM6427

- `Books/`: Shelf, a simple, elegant book app showing the top 5 trending books, the top 3 genres, and the top 10 US authors. Covers, author photos and genre picks come live from the free [Open Library](https://openlibrary.org/developers/api) API (no key needed).
- `weather/`: a glassmorphic weather app powered by [Open-Meteo](https://open-meteo.com/).

Plain HTML/CSS/JS, no build step. To deploy the book app on Netlify, leave the build command empty and set the publish directory to `Books` (or drag the `Books` folder in).
